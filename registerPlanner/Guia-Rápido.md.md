# 🚀 Guia Rápido - Valut

## Comandos Essenciais

### 📅 HOJE
1. Abra o registro diário: `Ctrl/Cmd + P` → "Daily Note"
2. Revise tarefas pendentes: Vá para `Dashboard/Tarefas.md`
3. Defina 3 prioridades principais

### 📝 REGISTRO RÁPIDO
- Ação importante: Use template "Movimento Consciente"
- Problema: Use template "Problema Crítico"
- Ideia: Use template "Insight Rápido"

### 🔍 ENCONTRAR INFORMAÇÃO
- Busca geral: `Ctrl/Cmd + O`
- Busca em conteúdo: `Ctrl/Cmd + Shift + F`
- Tarefas: Vá para `Dashboard/Tarefas.md`

## Fluxo Diário Recomendado

### Manhã (5 min):
1. Abra registro diário
2. Defina intenções do dia
3. Revise prioridades

### Tarde (2 min):
1. Registre progressos
2. Ajuste rota se necessário

### Noite (8 min):
1. Registre aprendizados
2. Planeje amanhã
3. Feche tarefas concluídas

## Atalhos de Template
- Diário: `{{date}}`
- Hora: `{{time}}`
- Semana: `{{date:YYYY-[W]WW}}`
- Mês: `{{date:YYYY-MM}}`

## Emergência
Se sentir sobrecarregado:
1. Respire fundo
2. Abra apenas o registro diário
3. Anote apenas 3 coisas
4. Volte amanhã
